# Pulse and complete-debit calculations

`check_pulse_and_debit.py` uses Python, NumPy and SciPy. Run it from any directory; it prints JSON and does not modify the archived output `pulse_and_debit.json`.

It checks the deterministic compact-pulse example in the selected-source section, the complete quartet entropies and the drive/heat benchmarks next to the maintained-access conjecture. The pulse is normalized independently at two Fourier cutoffs and quadrature orders. Agreement is a numerical stability check, not an interval certificate or a reconstruction of a BRAIN calibration experiment.

The window-scaling table only illustrates the distinction between sparse exploration and sustained response-sensitive decisions. It does not construct a physical sorting delay, sensor or sustained apparatus. Initial correlations, work and nonthermal exports retain the assumptions of the article.
