# F-III source notes

FIII_quantum_imports retains the complete fixed-history channel, source, renewal and finite-return arguments imported from Q-RAIF C. These quantum interfaces are distinct from the paper's finite semiclassical mean-action return.

These TeX fragments are reading/source material, not independent papers. They use the notation, macros, citations and labels of the owning article. Read them with that article; do not concatenate them into it without resolving duplicate labels. Full proofs moved here remain available, while historical corrections do not reinstate retired claims. The fixed source manifest hashes these files together with the current article.
