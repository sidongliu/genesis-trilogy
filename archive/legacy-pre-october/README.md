# Earlier repository materials

These files preserve the repository's earlier manuscripts, collected volumes,
scripts and author notes. They were moved here without changing their contents
when the October 2026 edition became the current reading route.

They are historical material, not an alternative current edition. Earlier
claims, examples and explanatory mappings may have been revised or replaced.
The author notes are exploratory writing, not peer-review certification or
additional evidence for the current papers.

- Current papers: [papers](../../papers/)
- Current collected volumes: [collections](../../collections/)
- Current reading guide: [repository README](../../README.md)
- Separately preserved published July edition: [24 July 2026](../2026-07-24/)

This directory retains the earlier repository layout, including its root
`arxiv.sty`, so historical source relationships remain visible. It is not a
replacement for the dated July publication archive. `FILES.sha256` records the
unchanged archived file contents; check it from this directory with
`shasum -a 256 -c FILES.sha256`.

Archiving does not make these materials private or remove their Git history.
