\section{Why the July 2026 derivation is not used}\label{app:july}

The July 2026 version of this paper derived a half-sided modular inclusion from the
axiom package \((U1)+(C)+(\mathrm{Amb})+(CN_\exists)\) and deduced an
``inseparability theorem'' with a canonical-scale refinement. The route fails, for the
following reasons.
\begin{enumerate}[leftmargin=2em,itemsep=2pt]
\item \emph{The ambient shell rule collapses.} With the defect pseudo-distance bounded by
\(2\|x\|\), the shell defined by the rule contains a full ball of the ambient algebra
and hence equals the ambient algebra; the unit-sphere variant fails the same way.
\item \emph{A sign error in the Tomita relations.} \(J\) is antilinear, so
\(J\Delta^{is}J=\Delta^{is}\); with this correction the compressed half-line, the
covariance exponent and the direction of the inclusion all change together, and a single
sign cannot be repaired in isolation.
\item \emph{The scale datum.} For a fixed vacuum, the modular generator annihilates
the vacuum, so its variance vanishes identically; the truncated one-sided variance
diverges and the sign of its finite part depends on the regularisation.
\item \emph{``\(\mathrm{Out}(M)=\{e\}\)'' is false} (approximately inner is not inner).
\item \emph{``Cyclic and separating'' for faithful states.} Faithfulness gives
separating only.
\end{enumerate}
None of these affects the statements proved here, which use Theorems~\ref{thm:AZ} and
\ref{thm:GLW} directly.
