# July 2026 edition

This directory preserves the files published on Zenodo on 24 July 2026: 127 attachments across 36 records, comprising 36 manuscript or collection PDFs, 36 TeX files and 55 supplementary files. The files retain their original contents and hashes. `MANIFEST.json` lists each record, concept DOI, filename, size, SHA-256 and MD5; `SHA256SUMS.txt` checks the preserved files.

`arxiv.sty` is supplied as an additional build dependency from the original local staging. It was not included in the July list of 127 published attachments. The historical internal upload guide is not part of this public archive.

The manuscripts, titles and assumptions in this edition were substantially revised in October. This archive is a historical record, not the current statement of the theory. Start with the [current reading guide](../../README.md) for the October edition. In particular, do not combine a July manuscript or supplement with an October PDF and treat them as one version.

The original TeX packaging is retained. Some collected-volume TeX files depend on member PDFs, and older build arrangements may need path adjustments; this archive is not a claim that the historical sources now rebuild unchanged in every environment. The current edition has separate source bundles and build instructions.
